`splash-author.png` conserva la composición aprobada con un único cambio solicitado:

Edición realizada con el generador visual integrado. Instrucción de edición:
Reemplazar únicamente el texto inferior «*// -- Splash Autor --*» por
«Desarrollado por Luics415», conservando tipografía cian monoespaciada, centrado,
ancla, lente, colores, fondo, marco, ADMIN, INVITADO, título, versión,
estado de carga, composición y dimensiones.

El distintivo INVITADO del arte se conserva como parte de la composición aprobada.
En dev.6 ambas manos pueden usarse simultáneamente como principal y auxiliar,
sin fijar esos roles a la izquierda o derecha. No se altera el arte para esta corrección.
