# Política de cookies

**Bio-Gesture Control Pro · vigente desde el 28 de septiembre de 2026**

La aplicación de escritorio no es un sitio web: no crea, lee ni almacena cookies, identificadores publicitarios, píxeles ni tecnologías equivalentes. Por eso el funcionamiento local actual no necesita un banner de consentimiento de cookies.

El repositorio en GitHub y cualquier página que GitHub aloje son servicios independientes. GitHub puede usar cookies técnicas y otras tecnologías conforme a su propia política y configuración. Si el proyecto incorpora una web propia, analítica, publicidad o cookies no esenciales, se documentarán por separado y se solicitará consentimiento previo cuando la ley aplicable lo exija, con una opción real para rechazar y cambiar la elección.

Para revisar o borrar datos del navegador, usa los controles del navegador y la política del proveedor correspondiente.
