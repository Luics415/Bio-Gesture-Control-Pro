# Reportar una vulnerabilidad

Bio-Gesture Control Pro es un proyecto de escritorio. La versión actual no mantiene un servidor propio, cuentas ni una API pública.

Si encuentras una vulnerabilidad, no publiques capturas, diagnósticos, claves ni datos personales en un issue. Usa la función privada de reporte de vulnerabilidades de GitHub o un Security Advisory del repositorio cuando esté habilitada. Si no aparece disponible, solicita por el perfil de Luics415 un canal privado antes de compartir detalles.

Incluye únicamente la versión y el sistema operativo, pasos mínimos para reproducir, impacto observado y una corrección o mitigación si la conoces. No se garantiza un plazo de respuesta ni que una versión de desarrollo sea adecuada para un entorno crítico.
